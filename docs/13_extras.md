# Extras

## Nombre del juego
"PPT64" o "Piedra Papel Tijeras 64 bits" es el nombre estético del proyecto.
"64 bits" hace referencia al estilo visual pixel art retro (era de 8/16/64 bits),
no a ninguna mecánica técnica del juego. Ver ADR-0003 para la implementación del estilo.

## Módulo Go
El nombre del módulo Go es `ppt64` (definido en `go.mod` al crear el scaffolding).
